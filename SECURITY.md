# Security policy

## Scope

This repository contains a public GitHub profile, portfolio material and repository-local validation tooling. Report security issues in this repository here; vulnerabilities in linked products belong in their respective upstream repositories. A portfolio entry is not a product support or release guarantee.

## Confidential reporting

Use the [private vulnerability reporting form](https://github.com/mohammadmohammadzadeh19960-code/mohammadmohammadzadeh19960-code/security/advisories/new) (Security → Report a vulnerability). Include the affected file or commit, impact and a minimized reproduction. Do not include credentials, private project data, personal documents or unredacted logs. If the form is unavailable, request a confidential contact channel without publishing vulnerability details.

Ordinary documentation feedback may use the repository Issues tab when enabled.
